## Pourquoi la suite Quai ?

Vous en avez assez des logiciels gratuits qui affichent des pubs, réclament un compte, vous pistent ou ressemblent à Windows XP ? Nous aussi.

La suite Quai, c'est une promesse simple :

- **De vraies applications Windows.** Natives (WinUI 3), rapides, au look de Windows 11, en thème clair ou sombre. Aucune page web déguisée, aucun navigateur embarqué.
- **Vos données restent chez vous.** Pas de compte, pas de cloud imposé, pas de pistage. Point.
- **Gratuit. Vraiment.** Pas de version « Pro », pas d'abonnement, pas de fonction bloquée derrière un paiement.
- **En français, d'abord.** Des mots clairs, pas de jargon inutile.
- **Toujours à jour, en un clic.** Une nouvelle version ? Un bouton, et l'application se met à jour puis redémarre toute seule.
- **Une famille cohérente.** Même philosophie, même installation, mêmes habitudes d'une application à l'autre.

## Quai — vos serveurs, vos fichiers et vos appareils, dans une seule fenêtre

<p align="center">
  <img src="https://raw.githubusercontent.com/memton80/quai-ssh/main/docs/images/connexions.png" alt="Le carnet de connexions de Quai : dossiers, étiquettes et recherche">
</p>

**Fini PuTTY + WinSCP + le post-it de mots de passe.** Quai réunit SSH, SFTP et port série dans une application moderne, légère et agréable.

- **Tous vos serveurs, bien rangés** : dossiers, étiquettes, recherche instantanée.
- **Un vrai terminal** propulsé par le moteur de Windows Terminal, avec onglets.
- **Connexion éclair** : tapez `alice@serveur`, Entrée, c'est connecté.
- **Vos fichiers par glisser-déposer** : votre PC à gauche, le serveur à droite.
- **Éditez un fichier distant** dans votre éditeur préféré : chaque enregistrement repart sur le serveur.
- **Vos commandes favorites** à portée de raccourci (`Ctrl+Maj+P`).
- **Reconnexion automatique** après une coupure Wi-Fi ou une sortie de veille.
- **Routeurs, switchs, Raspberry Pi, Arduino** : le port série est inclus.
- **PowerShell, CMD et WSL** dans un onglet, à côté de vos serveurs.
- **Sécurité sans effort** : mots de passe dans le coffre de Windows, vérification de l'identité de chaque serveur.

## Quai PDF — lire et retoucher vos PDF, sans prise de tête

<p align="center">
  <img src="https://raw.githubusercontent.com/memton80/quai-pdf/main/docs/images/document.png" alt="Quai PDF : les vignettes à gauche, la page à droite">
</p>

**Un PDF à remettre d'aplomb, à trier, à assembler ?** Plus besoin d'un logiciel lourd, payant ou d'un site web douteux où envoyer vos documents. Quai PDF fait l'essentiel, sur votre PC.

- **Lire confortablement** : vignettes, zoom, ajustement à la largeur.
- **Copier du texte** à la souris, comme sur une page web.
- **Pivoter** une page scannée de travers (`Ctrl+R`).
- **Réorganiser** les pages par simple glisser-déposer.
- **Supprimer** les pages inutiles.
- **Assembler** plusieurs PDF en un seul (`Ctrl+I`).
- **Extraire** quelques pages dans un nouveau fichier (`Ctrl+E`).
- **Renseigner** titre, auteur, sujet et mots-clés.
- **Annuler sans stress** : rien n'est écrit sur le disque avant « Enregistrer ».
- **Respect de vos documents** : un PDF protégé s'ouvre en lecture seule, sa protection n'est jamais retirée dans votre dos.

Sous le capot, rien n'est réinventé : le moteur PDF de Windows pour l'affichage, PDFium (celui de Chrome) pour le texte, PDFsharp pour les modifications. Du solide.

## Installer en une minute

1. Téléchargez l'installeur de l'application qui vous intéresse (`-x64.exe`, ou `-arm64.exe` pour un PC Snapdragon / ARM).
2. Lancez-le : **pas besoin d'être administrateur**, tout est inclus.
3. C'est prêt, l'application vous attend dans le menu Démarrer.

> Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » : les applications Quai sont des projets indépendants dont les fichiers ne sont pas encore signés. Cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.

Compatible **Windows 10 et Windows 11**. Une version portable (zip, sans installation) est aussi disponible.
